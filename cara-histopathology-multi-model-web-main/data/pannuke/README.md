# PanNuke goes here

Place the three official folds in this folder (the archive layout works as downloaded):

```
Fold 1/images/fold1/images.npy  + types.npy
Fold 2/images/fold2/images.npy  + types.npy
Fold 3/images/fold3/images.npy  + types.npy
```

Then run `python scripts/prepare_pannuke.py` from the project root. See the main README, section 3.
